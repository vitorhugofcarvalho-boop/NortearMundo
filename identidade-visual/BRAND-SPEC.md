## Contexto

- **Marca:** Nortear Mundo — agência de viagem personalizada (Luna Carvalho + Caroline Lisboa, RN). "A gente não vende pacote. A gente cuida do seu sonho."
- **Peça-alvo:** landing de captura do **Radar de Milhas** = grupo GRATUITO de WhatsApp com ofertas de passagens por milhas/promoções. Topo de funil (lead magnet).
- **Arquétipo:** Explorador (primário: horizonte, aventura, descoberta) + Cuidador (complementar: suporte humano, calor, confiança).
- **Promessa do grupo:** "As melhores oportunidades de viajar gastando pouco chegam até você — sem caçar, sem perder, com quem entende de verdade."
- **Personalidade:** É → acolhedor, confiável, aventureiro. NÃO É → corporativo-frio, sensacionalista/spam, urgência falsa.
- **Voz:** "a gente" (nunca "nós"), reframe "não X, é Y", itálico p/ confidência, prova social hiper-específica (nome+destino+mês), regionalidade nordestina como ativo.
- **Contatos reais:** WhatsApp `5584994055713` · `@nortearmundo` · `oi@nortearmundo.com.br` · "Feito com cuidado, no Nordeste 🌊".

**DECISÃO DO CLIENTE (vigente, 2026-06-19): Newsreader + Figtree + Space Mono** — ver `TIPOGRAFIA-V2.md`, "Opção 3 — Notícia Calorosa". Motivo: o Playfair Display é uma serif de contraste de traço extremo que perde legibilidade em tamanhos médios/pequenos em tela. Newsreader é serif feita para leitura em tela (Production Type) com itálicos expressivos para a confidência da marca, Figtree é humanista de alta legibilidade no corpo, e Space Mono mantém o efeito "boarding pass". *(Revisão: por um período a escolha registrada foi a Opção 2 Lora + Source Sans 3 + IBM Plex Mono — substituída pela Opção 3.)* Os 4 pares abaixo permanecem documentados como histórico da exploração.

## TOKENS CSS BASE (compartilhados; cor entra por tema)
```css
:root{
  --font-display:'Playfair Display',Georgia,serif;
  --font-body:'DM Sans',system-ui,sans-serif;
  --font-mono:'DM Mono',ui-monospace,monospace;
  --text-display:clamp(2.4rem,7vw,5rem);
  --text-h1:clamp(2rem,5vw,3.4rem);
  --text-h2:clamp(1.5rem,3.5vw,2.4rem);
  --text-h3:clamp(1.15rem,2vw,1.4rem);
  --text-body:clamp(1rem,1.2vw,1.075rem);
  --text-eyebrow:.72rem; /* mono uppercase tracking .18em, cor accent */
  --radius-sm:8px; --radius-md:12px; --radius-lg:20px; --radius-pill:999px;
  --space-section:clamp(64px,10vw,112px);
  --gutter:clamp(20px,8%,120px);
  --ease:cubic-bezier(.22,1,.36,1);
  --shadow-md:0 8px 24px rgba(12,51,80,.10),0 2px 6px rgba(12,51,80,.05);
  --shadow-lg:0 18px 48px rgba(12,51,80,.14),0 4px 12px rgba(12,51,80,.06);
}
```
Fontes via Google Fonts link (entregável standalone). Body line-height 1.7. Eyebrows sempre mono uppercase tracking .18em na cor do acento. WhatsApp green #25D366 reservado só para botão "entrar no grupo".

## CRAFT obrigatório (ambos os arquivos)
- Responsivo fluido (clamp), mobile-first, testar 360/768/1280.
- Scroll-reveal sutil via IntersectionObserver; respeitar `prefers-reduced-motion: reduce`.
- Gradiente "respirando" lento no hero navy (igual `.nm-radar` do Design.md) + glow do acento.
- CTA com micro-pulso (para no hover). Hover de card: translateY(-4px)+sombra.
- Off-white/grafite nunca puros. Acessibilidade: foco visível, labels, contraste AA.
- 100% em Português do Brasil.
